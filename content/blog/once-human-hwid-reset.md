Once Human HWID reset questions show up every time someone builds a new box. The license is bound to hardware. Moving PCs without a reset leaves the old machine holding the key.

## Portal reset first

Open the operator portal with the email you used at checkout. If the HWID reset control is available, use it, then download the loader on the new PC. Limits depend on your plan and how recently you last reset.

If the button is greyed out, wait out the cooldown or email support with the order address and a short reason (new PC, Windows reinstall). Include the old and new machine notes if staff ask. Do not open five tickets.

## What a reset does not do

It does not restore a banned Once Human account. It does not skip Cloud DMA setup on the new machine. It does not migrate random forum configs unless you export them yourself.

Save configs before you wipe the old drive. Cloud save/load is listed in misc; a local export is cheaper insurance. See [config presets](/blog/once-human-hacks-config-presets/).

## The HWID Spoofer utility

[HWID Spoofer](/products/once-human-hacks/hwid-spoofer/) is a separate product: hardware identifier changes (disk serials, MAC addresses, GPU IDs, and related IDs) with a cleaner. Cloud DMA is listed as required for full functionality. Administrator rights are required. Run spoof and cleanup before launching Once Human, in the order the current portal guide shows.

That listing is not a Fair Play workaround. Confirm the live Once Human notes on checkout. If you only needed a license move, the portal reset is the tool, not another SKU.

## After the new PC boots

Install Once Human. Apply the game patch. Confirm status is online. Download the loader from the portal, not a Discord file. Follow the [setup guide](/blog/once-human-hacks-setup-guide/). If Defender flags the download, exclude the portal folder only.
