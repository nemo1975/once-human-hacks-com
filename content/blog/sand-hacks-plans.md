Sand Hacks on sandhacks.com is one main product plus three utilities. **Complete** is the SAND: Raiders of Sophie suite. **Cloud DMA**, **HWID Spoofer**, and **Skin Changer** are separate merchant checkouts.

This guide maps merchant-listed module **groups** to how people actually raid—without inventing features that are not on checkout.

## The catalog at a glance

| Product | You get (merchant groups) | Typical raid role |
| ---- | ------------------------- | ----------------- |
| [Complete](/products/sand-hacks/complete/) | Aimbot + Player ESP + Trampler + Item ESP + Radar + Object ESP + Misc | One key for cities, decks, dunes |
| [Cloud DMA](/products/sand-hacks/cloud-dma/) | Single-PC Hyper-V delivery layer | Infrastructure for listed utilities |
| [HWID Spoofer](/products/sand-hacks/hwid-spoofer/) | Hardware IDs plus cleaner | SAND: Raiders of Sophie |

Module names on the seller page are authoritative. If a label changes after a patch, trust checkout over a blog screenshot.

## Complete: when one key beats two configs

Complete is for raiders who do not want to split awareness and fights across two products. Merchant copy groups include:

- **Aimbot:** hotkey, FOV, bones, humanized trajectories, prediction, visibility, dynamic FOV, smoothing, team filter, max distance
- **Player ESP:** players, NPCs, teams, nicknames, IDs, distance, health, shield, held item, kit, boxes, skeleton, head/direction indicators, snaplines, max ESP distance
- **Trampler:** player/NPC Trampler tracking, loot visualization, Trampler radar
- **Item ESP:** weapons, ammo, consumables, armor, backpacks, valuables, keys, resources, explosives
- **Radar:** 2D radar, smooth rotation, labels, indicators, adjustable range and size
- **Object ESP:** containers, lockboxes, loot types, barrels, mines, Aurogen, ladders, treasure, turrets, Dreadnaught, captain quarters, corpses, projectile shields
- **Misc:** compass, crosshair styles, FPS/time/resolution, menu key, panic key, colors, config save/load

Use Complete when you:

- Run contested city extracts and need both deck reads and rifle assist
- Hijack Tramplers and want loot visualization plus aim during deck fights
- Want every listed Sand Hacks group on one license

Toggle modules you do not want. You do not need a second Sand Hacks product to run ESP without aim.

## Checkout rhythm

1. Open [Complete](/products/sand-hacks/complete/) on the [Sand Hacks hub](/products/sand-hacks/)
2. Add Cloud DMA, HWID Spoofer, or Skin Changer only if those utility listings match your PC setup
3. Finish on the merchant page. Pick duration there; we do not duplicate billing copy on sandhacks.com

After payment: portal loader, test in a quiet scav, save presets per [config guide](/blog/sand-hacks-config-presets/), then push harder extracts.

## Risk is not a catalog feature

SAND does not grade you on which modules you enabled. Third-party tools can violate game rules whether aim is on or off. Read [account risk](/blog/sand-hacks-account-risk/), watch status, and never raid while the banner shows offline.

## Pick your setup in three questions

1. Do you need Trampler, item ESP, aimbot, and radar this week? If yes, start with **Complete**.
2. Do you need the listed Hyper-V delivery layer, hardware ID cleaner, or cosmetic client? If yes, add those **utilities**.
3. Do you want one config file for city and dune nights? If yes, **Complete**—save presets instead of buying a second hacks plan.
