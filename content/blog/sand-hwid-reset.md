Sand Hacks licenses bind to hardware identifiers. New GPU, fresh Windows install, or a brand-new box means you need an **HWID reset** before the loader accepts your key again.

This is a license move guide—not a SAND ban bypass guide.

## When to reset

Reset after:

- Replacing motherboard or CPU
- Reinstalling Windows on the same machine
- Moving from desktop to laptop for travel raids

Do not reset because aim felt bad last night. Cooldowns exist.

## Portal reset steps

1. Log into the operator portal with checkout email.
2. Open license or HWID section.
3. Click reset if enabled and follow confirmation steps.
4. Download the current loader build from the portal—not an old desktop copy.
5. Run [setup guide](/blog/sand-hacks-setup-guide/) launch order again.

## Greyed-out reset button

Common causes:

- Reset used within cooldown window
- Chargeback or billing flag on the order
- Support ticket already open

Email [support](/support/) with order ID, old and new Windows versions, and a short explanation. Forum anecdotes: [HWID thread](/forum/new-pc-license-transfer-hwid/).

## Cloud configs after reset

Config save/load and cloud backup should follow the license after a successful reset. Still export local backups before you wipe the old PC.

## Security hygiene

After reset:

- Revoke old loader copies on the sold PC
- Do not share portal passwords
- Do not post keys in Discord public channels

## Cooldown etiquette

If reset fails once, wait and read portal copy before spamming support. Duplicate tickets slow everyone on patch weekend. Include one screenshot of greyed-out button and your license expiry if shown.

## Selling old hardware

Wipe loader folders before handing off the PC. Licenses are personal; buyers should not inherit your portal session cookies from a browser profile either.

## Virtual machines

VM gaming with Sand Hacks is unsupported noise in most tickets. Expect HWID weirdness. Use bare metal Windows for predictable binding.
